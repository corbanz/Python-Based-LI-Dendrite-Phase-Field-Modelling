# Python-Based-LI-Dendrite-Phase-Field-Modelling
Python phase-field model of lithium dendrite growth with thermal effects. A learning-oriented replication of Yan et al. (2018), built in verified stages starting from Allen–Cahn.

This is an undergraduate research project with two goals: to learn how phase-field models are built and solved, and to work toward replicating the thermal-effect study by Yan et al. (2018), "A computational investigation of thermal effect on lithium dendrite growth." The model is built up in verified stages rather than all at once.
